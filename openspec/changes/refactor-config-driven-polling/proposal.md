# Change: 全面配置驱动的 MCP 工具链轮询与等待

## Why
当前 MCP 工具链存在硬编码等待与轮询策略，导致不同页面状态下行为不可调、难以复用与排障。需要将所有轮询/等待逻辑统一改为配置驱动，并在配置缺失时直接失败，保证可控性与一致性。

## What Changes
- **BREAKING** MCP 工具链内所有轮询/等待逻辑改为配置驱动（超时、轮询间隔、重试策略均来自配置）。
- **BREAKING** 配置缺失即报错，不再使用代码内默认值兜底。
- 按模块拆分配置结构（例如发布、互动、数据分析、登录/会话等）。
- 增加配置校验，启动时检查必填配置完整性并给出明确错误。

## Impact
- Affected specs: mcp-tools（新增）
- Affected code: MCP 工具链相关的所有等待/轮询逻辑（发布、草稿、互动、数据等模块）
