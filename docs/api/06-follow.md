# 关注/取关 API

## 概述

关注或取消关注小红书用户。

## 接口信息

**模块**: `follow.go`
**功能**: 关注用户、取消关注

## JSON Schema

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "FollowUser",
  "description": "关注或取消关注用户",
  "type": "object",
  "required": ["user_id", "xsec_token", "action"],
  "properties": {
    "user_id": {
      "type": "string",
      "description": "用户ID",
      "examples": ["5f7e1234567890abcdef"]
    },
    "xsec_token": {
      "type": "string",
      "description": "安全令牌",
      "examples": ["abc123def456"]
    },
    "action": {
      "type": "string",
      "description": "操作类型",
      "enum": ["follow", "unfollow"],
      "examples": ["follow"]
    }
  }
}
```

## 字段说明

| 字段 | 类型 | 必填 | 可选值 | 说明 |
|------|------|------|--------|------|
| `user_id` | string | ✅ | - | 用户ID |
| `xsec_token` | string | ✅ | - | 安全令牌 |
| `action` | enum | ✅ | follow/unfollow | 关注或取消关注 |

## 调用示例

### 示例 1: 关注用户

```json
{
  "user_id": "5f7e1234567890abcdef",
  "xsec_token": "abc123def456",
  "action": "follow"
}
```

### 示例 2: 取消关注

```json
{
  "user_id": "5f7e1234567890abcdef",
  "xsec_token": "abc123def456",
  "action": "unfollow"
}
```

## 响应格式

### 成功响应

```json
{
  "success": true,
  "action": "follow",
  "user_id": "5f7e1234567890abcdef",
  "message": "关注成功"
}
```

### 失败响应

```json
{
  "success": false,
  "error_code": "ALREADY_FOLLOWED",
  "message": "已经关注该用户"
}
```

## 错误代码

| 错误代码 | 说明 |
|----------|------|
| `USER_NOT_FOUND` | 用户不存在 |
| `INVALID_XSEC_TOKEN` | 安全令牌无效 |
| `ALREADY_FOLLOWED` | 已经关注该用户 |
| `NOT_FOLLOWED_YET` | 尚未关注，无法取消关注 |
| `CANNOT_FOLLOW_SELF` | 不能关注自己 |
| `USER_BLOCKED` | 用户已被拉黑 |
| `FOLLOW_LIMIT_EXCEEDED` | 超过关注数量限制 |

## 功能特性

### 1. 幂等性保证

- **重复关注**: 如果已关注，自动跳过，不报错
- **重复取消**: 如果未关注，自动跳过，不报错
- 确保操作的稳定性和安全性

### 2. 状态检测

- 操作前自动检测当前关注状态
- 已关注状态下跳过关注操作
- 未关注状态下跳过取关操作

### 3. 智能判断

- 自动查找关注按钮
- 支持多种页面样式
- 验证操作结果

## 关注关系类型

| 关系类型 | 描述 |
|----------|------|
| **未关注** | 双方无关注关系 |
| **单向关注** | 我关注对方，对方未关注我 |
| **互相关注** | 双方互相关注（好友关系） |
| **被关注** | 对方关注我，我未关注对方 |

## 关注限制

小红书平台对关注有以下限制：

1. **数量限制**:
   - 新用户关注上限较低
   - 随账号等级提升逐渐增加
   - 最高可关注5000人左右

2. **频率限制**:
   - 短时间内不能关注过多
   - 避免频繁关注/取关操作
   - 防止被识别为异常行为

3. **质量要求**:
   - 避免关注后立即取关
   - 避免批量关注陌生账号
   - 保持合理的关注/粉丝比例

## 使用场景

### 关注

- 关注感兴趣的创作者
- 关注朋友账号
- 关注品牌官方账号
- 建立内容社交网络

### 取消关注

- 清理不活跃账号
- 取关不再感兴趣的内容
- 管理关注列表
- 调整内容推荐

## 最佳实践

### ✅ 推荐做法

1. **有选择性地关注**: 关注真正感兴趣的创作者
2. **适度关注**: 不要一次性关注大量用户
3. **长期维护**: 避免频繁关注/取关
4. **互动为先**: 先互动再关注，建立真实联系
5. **定期清理**: 定期整理关注列表

### ❌ 避免行为

1. **批量操作**: 短时间内批量关注/取关
2. **关注后秒取关**: 影响账号信誉
3. **互粉互赞**: 纯粹为了数据的互动
4. **关注上限**: 达到关注上限后无法再关注
5. **异常频率**: 触发平台风控机制

## 关注数据意义

### 关注数

- 代表你感兴趣的内容方向
- 影响你的内容推荐
- 不影响你的账号权重

### 粉丝数

- 代表账号影响力
- 影响内容曝光量
- 影响合作机会

### 关注/粉丝比

- 个人账号: 1:1 到 1:10 正常
- 创作者: 1:10 到 1:100+ 优秀
- 明星/大V: 1:1000+ 顶级

## 通知提醒

### 关注操作

- ✅ 对方会收到关注通知
- ✅ 显示在对方的新增粉丝列表
- ❌ 取消关注不会通知对方

### 互关状态

- 互关后可以查看对方私密笔记（如果允许）
- 互关后可以私信聊天
- 互关后在评论区显示"互相关注"标识

## 隐私设置

用户可以设置：
- **公开账号**: 任何人都可以关注
- **私密账号**: 需要审核同意才能关注
- **关注权限**: 仅允许互关好友查看笔记

## 注意事项

1. **尊重隐私**: 不要骚扰其他用户
2. **真实互动**: 建立真实的社交关系
3. **遵守规则**: 遵守平台关注规范
4. **账号安全**: 不要泄露账号信息
5. **理性关注**: 不盲目追求粉丝数
