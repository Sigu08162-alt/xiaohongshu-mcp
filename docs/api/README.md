## 通用说明

### xsec_token

大部分 API 都需要 `xsec_token` 安全令牌，该令牌可以从以下接口获取：
- 搜索接口返回的 Feed 列表
- 获取Feed列表接口
- 用户主页接口

### 数字格式

小红书对大数字使用缩写：
- `1.2w` = 12000
- `5000+` = 超过5000
- `10w+` = 超过100000

### 时间格式

- **时间戳**: Unix timestamp (毫秒)
  - 示例：`1706169600000`
- **定时发布**: ISO 8601 格式
  - 示例：`2026-01-27T10:30:00+08:00`

### 响应格式

所有 API 统一使用以下响应格式：

**成功**:
```json
{
  "success": true,
  "data": { ... },
  "message": "操作成功"
}
```

**失败**:
```json
{
  "success": false,
  "error_code": "ERROR_CODE",
  "message": "错误描述",
  "details": { ... }
}
```

## 使用限制

### 频率限制

为避免触发平台风控，建议：
- 发布笔记：每小时不超过3条
- 点赞/收藏：每分钟不超过10次
- 评论：每分钟不超过5条
- 关注：每小时不超过20个
- 搜索：每分钟不超过30次

### 内容限制

- 标题：1-20字符
- 正文：1-1000字符
- 图片：1-18张，支持JPG/PNG/WEBP
- 视频：建议15秒-5分钟，不超过500MB
- 标签：最多10个

### 账号限制

- 新账号功能受限
- 关注上限：约5000人
- 发布频率：根据账号等级

## 错误处理

### 常见错误代码

| 错误代码 | 说明 | 解决方案 |
|----------|------|----------|
| `NOT_LOGGED_IN` | 未登录 | 先调用登录接口 |
| `INVALID_XSEC_TOKEN` | 令牌无效 | 重新获取xsec_token |
| `RATE_LIMIT_EXCEEDED` | 频率超限 | 降低请求频率 |
| `PERMISSION_DENIED` | 权限不足 | 检查账号权限 |
| `CONTENT_INVALID` | 内容违规 | 检查内容合规性 |

### 重试策略

建议使用指数退避策略：
1. 首次失败：等待1秒
2. 二次失败：等待2秒
3. 三次失败：等待4秒
4. 三次后仍失败：停止重试

## 最佳实践

### 1. 错误处理

```javascript
try {
  const result = await api.publishImage(content);
  if (!result.success) {
    console.error('发布失败:', result.message);
    // 根据error_code做不同处理
  }
} catch (error) {
  console.error('请求异常:', error);
}
```

### 2. 频率控制

```javascript
// 使用队列控制请求频率
const queue = new RequestQueue({
  maxPerMinute: 10,
  maxPerHour: 100
});

await queue.add(() => api.likeFeed(feedId, token));
```

### 3. 令牌管理

```javascript
// 缓存xsec_token避免重复获取
const tokenCache = new Map();

function getToken(feedId) {
  if (tokenCache.has(feedId)) {
    return tokenCache.get(feedId);
  }
  // 从搜索结果或详情中获取
}
```
